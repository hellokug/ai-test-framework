脚本库

一个脚本 = 一个用例（测试意图）· 1 脚本 = 1 jsonl（1..N 行数据变体）· 先场景后用例 · GET /functional/scripts
层级口径：评估场景 = 功能大类（API 兼容性 / 参数校验 / FC …）→ 场景内以 脚本 = 用例（一个测试意图，类型标签 基础/边界/异常）组织 → 一脚本关联 1..N 行数据（每行 = content 内容 + params 参数 + 断言，行 = 变体，行级执行与判定，脚本结果 = 行级聚合）。
两条来源，同一落点：① 从 0 创建（前端结构化编辑三要素，harness 真实校验）； ② 从数据集导入（外部构造 jsonl，同一校验按行导入）——最终都物化为场景目录 1 脚本 = 1 jsonl 文件； 可挂外部平台用例编号（用例平台 ↔ 平台脚本的对应关系）。
执行口径：创建任务 = 选场景（全选/多选/散选子用例）；单脚本验证 = 行内「定向执行」（tools.cases 精确定向）。
