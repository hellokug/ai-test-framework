> 状态：**暂缓**（2026-08-28）。需求已对齐完毕，当前优先测试框架整体能力补齐。
> 恢复实施时从 M0 开始，无需重新对齐。对齐结论见文末。

## 项目概述

搭建大模型、RAG、Agent 通用 AI 评测平台的数据集管理核心模块，用于私有业务
封闭评测数据集的全生命周期管理，解决线上 bad-case 沉淀、训练-评测集语义泄露、
数据集漂移、尺子质量退化、金标集污染等工程痛点。

## 数据集分层架构（硬性约束）

三池独立存储，业务隔离：

1. **金标封闭 Holdout-Golden**
   - 定位：上线验收、模型版本对比的基准尺子
   - 量级：200-500 条；高质量人工双人精标；冻结后模型迭代期间禁止改动
   - 严格与训练集、知识库做泄露隔离；样本流入训练侧后禁止再入金标集
   - 修复线上 Bad-Case 后禁止原题入库，需构造推理衍生样本规避语义泄露
2. **自动化回归题库**
   - 定位：海量长尾 badcase、边界样本；自动化回归监控模型退化
   - 量级：5000-20000；LLM-Judge 自动打分；结果仅预警，不可阻断上线验收
   - 定期筛选优质样本升级迁移至金标集
3. **独立探针库**
   - 幻觉陷阱、歧义、无答案 case、Agent 误调用工具等高风险边界用例
   - 独立统计缺陷检出率

## 模块1：Bad-Case 闭环入库流水线

1. 根因标签：模型缺陷 / 临时环境故障 / 用户脏输入 / 业务过期下线
2. 决策分支：
   - 临时故障、业务过期 → 抛弃，不入任何评测库
   - 高频刚需缺陷 → 推荐流向训练增强集，打"禁止入金标"标签
   - 长尾边界 case → 推荐存入自动化回归题库
   - 高代表性核心业务缺陷 → 推荐人工审核后升级沉淀进金标集
3. 审计：每次样本增删改记录样本 ID、变更前后内容、变更人、变更理由；
   数据集版本快照

## 模块2：泄露风险检测引擎（精确+语义双层）

执行顺序：精确字符串匹配 → 关键词重叠校验 → BGE-M3 稠密向量语义相似度 → 复审清单。

1. 精确匹配：候选评测样本 vs 训练集/知识库文本，完全命中标记高泄露风险
2. 向量相似度（BAAI/bge-m3 余弦相似度）阈值：
   - ≥0.90 极高风险（疑似同义泄露）
   - 0.80-0.89 中等预警风险
   - <0.80 低风险放行
3. **业务约束：相似度仅为预警指标，程序不能自动判定泄露**；输出风险列表，
   人工复核三条件：用户核心诉求是否一致 / 标准答案是否一致 /
   看过训练样本是否可直接答对评测样本
4. 双向泄露巡检：定时全量扫描老金标样本是否被后续新增知识库文档
   造成"后发泄露污染"，输出巡检报告

## 模块3：数据集版本迭代质量评估

V1→V2 定量评估变好/变差；**禁止单纯依靠模型跑分判定数据集质量**。

1. 标注质量：Cohen-Kappa 标注一致性系数对比（V1 vs V2）
2. 分布漂移：
   - BGE-M3 向量，评测集与线上真实 Query 集向量中心点余弦距离
   - K-means 聚类，对比线上主题占比与新旧数据集主题分布占比，
     识别"重心相同但聚类结构失衡"的隐蔽漂移
3. 探针缺陷检出率对比：固定缺陷探针模型，对比 V1/V2 检出缺陷能力
4. 分层样本统计报表：各难度、业务场景样本数量变化
5. 输出完整质量变更报告 + 数据集升级是否通过的建议

## 模块4：数据集治理管控规则校验

1. 金标集扩容速率：每月新增上限 20-30 条，超量告警
2. 三池迁移管控：回归样本升级金标强制走人工审核流程
3. 样本互斥：禁止同一样本同时出现在训练增强集 + 金标集
